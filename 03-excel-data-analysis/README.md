# Excel Data Analysis & Reporting

## Overview

This project contains several Excel-based exercises focused on sales analysis, employee data management, logical functions, and PivotTable reporting.

## Objectives

- Analyze sales data
- Organize employee information
- Apply logical Excel functions
- Summarize business data using PivotTables
- Create structured reports for analysis

## Excel Skills Used

- IF
- Excel Formulas & Functions
- Data Organization
- Data Analysis
- PivotTable
- Basic Reporting

## Workbook Structure

- Sales Analysis — product sales analysis
- Employee Lookup — employee-related calculations using IF functions
- Employee Data — structured employee information
- Sales Pivot Report — sales data prepared for PivotTable analysis
- Pivot Summary — summarized sales report by category and month

## Result

The project demonstrates the use of Excel for organizing, analyzing, and summarizing business-related data.
