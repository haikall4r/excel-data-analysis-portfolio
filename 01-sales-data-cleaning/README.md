# Sales Data Cleaning

## Overview

This project focuses on cleaning and organizing raw sales data using Microsoft Excel.

## Objectives

- Clean inconsistent data
- Standardize text formatting
- Improve data consistency
- Prepare data for further analysis

## Excel Skills Used

- TRIM
- PROPER
- IF
- COUNTIF
- SUMIF
- Data Cleaning
- Basic Data Analysis

## Result

The cleaned dataset is prepared for further analysis, reporting, and visualization.
