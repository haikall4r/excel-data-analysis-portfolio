# Sales Performance Dashboard

## Overview

This project focuses on analyzing sales performance and presenting key sales information through an Excel dashboard.

## Objectives

- Analyze sales revenue and quantity
- Summarize sales performance by product
- Analyze sales performance by category
- Create a simple and informative dashboard

## Excel Skills Used

- SUM
- AVERAGE
- COUNTA
- PivotTable
- Data Analysis
- Data Visualization
- Dashboard Development

## Workbook Structure

- Sales Data — source sales data
- Pivot Analysis — sales analysis by product
- Pivot Category — sales analysis by category
- Dashboard — summary of sales performance

## Result

The dashboard provides a summarized view of sales performance that can be used to support basic business analysis and reporting.
